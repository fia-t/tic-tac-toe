# Арти кампанії - що де лежить і куди завантажувати

Усе нижче **вже підключено**: гра бере ці картинки з `public/`, а розділи кампанії занесено
в базу (`node scripts/seedCampaign.js`). Нічого завантажувати не обов'язково. Ця папка - копії
для перегляду й на випадок, якщо захочеш замінити картинку чи зробити новий розділ/скін в адмінці.

## 1. Фони розділів - `1-fony-rozdiliv/`

| Файл | Розділ | Де в грі | Куди завантажувати |
|---|---|---|---|
| `beach.jpg` | Пляж (розділ 1) | мініатюра розділу на сторінці «Кампанія», картки альбому | Адмінка → **Кампанія** → розділ «Пляж» → «Фон розділу» |
| `forest.jpg` | Ліс (розділ 2) | те саме | Адмінка → **Кампанія** → «Ліс» → «Фон розділу» |
| `mountains.jpg` | Гори (розділ 3) | те саме | Адмінка → **Кампанія** → «Гори» → «Фон розділу» |

Поки фон в адмінці не завантажено, використовується вбудований файл
`public/images/campaign/<id>.jpg` (той самий, що тут).

## 2. Скіни-нагороди за розділи - `2-skiny/`

| Папка | Скін | Нагорода за | id скіна |
|---|---|---|---|
| `sea/` | «Морський бриз» | розділ «Пляж» | `sea` |
| `forest/` | «Лісовий» | розділ «Ліс» | `forest` |
| `peak/` | «Гірський» | розділ «Гори» | `peak` |

У кожній папці: `background.jpg` - фон поля, `x.svg` - фішка X, `o.svg` - фішка O.

Ці три скіни **вбудовані в гру** (`CAMPAIGN_THEMES` у `game/src/lib/themes.ts`, файли в
`public/images/themes/<id>-x.svg`, `<id>-o.svg`). Тому в адмінці «Теми» їх немає - і не треба.
У магазині вони показуються з позначкою «Нагорода за розділ …» і не купуються; гравець
отримує скін, коли проходить розділ.

Нагороду розділу міняють в адмінці → **Кампанія** → розділ → «Нагорода: скін» (список
вбудованих скінів кампанії + усі теми з «Теми»). Щоб зробити **свій** скін-нагороду:
адмінка → **Теми** → нова тема → завантажити фон / X / O (наприклад, файли з цієї папки) →
обрати її в розділі кампанії. Тема, обрана нагородою, у магазині теж не купується.

## 3. Боси - `3-bosy/`

| Файл | Бос | Розділ |
|---|---|---|
| `beach-kapitan-krab.svg` | Капітан Краб | Пляж, рівень 6 |
| `forest-pan-krit.svg` | Пан Кріт | Ліс, рівень 12 |
| `mountains-orel-vershyna.svg` | Орел-Вершина | Гори, рівень 18 |

Портрети вбудовані в код (`game/src/components/CampaignArt.tsx`) за id розділу, завантажувати
їх нікуди не треба. Для нових розділів, створених в адмінці, показується загальний портрет-корона.
Ім'я боса й фразу перед боєм редагують в адмінці → **Кампанія**.

## Повторне заливання розділів у базу

```bash
node scripts/seedCampaign.js          # додає лише розділи, яких ще немає в базі
node scripts/seedCampaign.js --force  # перезаписує наявні стандартними (правки з адмінки зникнуть)
```
